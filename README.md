# مشروع اختبار موقع SauceDemo باستخدام Playwright 🚀

هذا المشروع عبارة عن إطار عمل (Testing Framework) متكامل لاختبار موقع [SauceDemo](https://www.saucedemo.com/) باستخدام أداة **Playwright** ولغة **TypeScript**. تم بناء هذا المشروع لتلبية متطلبات تقييم جودة البرمجيات (Software Testing and Quality Assurance).

---

## 🌟 الميزات التي تم اختبارها (Tested Features)

يغطي هذا المشروع السيناريوهات الأساسية التالية:

1. **تسجيل الدخول (Login):**
   - اختبار تسجيل الدخول ببيانات صحيحة.
   - اختبار تسجيل الدخول ببيانات خاطئة.
2. **سلة المشتريات (Add to Cart):**
   - إضافة منتج واحد والتأكد من وجوده.
   - إضافة عدة منتجات معاً والتأكد من عددها داخل السلة.
3. **الدفع وإتمام الطلب (Checkout):**
   - إتمام عملية الشراء لمنتج واحد.
   - إتمام عملية الشراء لعدة منتجات والتحقق من السعر الإجمالي ورسالة النجاح.
4. **حذف المنتجات من السلة (Remove from Cart):**
   - إضافة منتج وحذفه والتأكد من أن السلة أصبحت فارغة.
   - إضافة عدة منتجات وحذفها واحداً تلو الآخر والتأكد من تحديث حالة السلة بعد كل حذف.
5. **الترتيب (Sort Feature):**
   - ترتيب المنتجات أبجدياً من (A-Z).
   - ترتيب المنتجات حسب السعر من الأعلى للأقل (High to Low).

## 💡 المفاهيم التقنية المستخدمة (Playwright Concepts)

تم استخدام أحدث تقنيات ومفاهيم Playwright لضمان جودة الكود وسرعته:

- **Page Object Model (POM):** تم فصل عناصر الصفحات (مثل صفحة تسجيل الدخول، سلة المشتريات) في مجلد `pages` لتسهيل صيانة الكود وإعادة استخدامه.
- **حفظ حالة المتصفح (Browser State):** بدلاً من تسجيل الدخول في كل اختبار، يقوم المشروع بتسجيل الدخول مرة واحدة فقط وحفظ الجلسة في ملف `.auth/user.json`، مما يجعل تنفيذ الاختبارات سريعاً جداً.
- **متغيرات البيئة (.env):** تم تخزين البيانات الحساسة (الرابط، اسم المستخدم، كلمة المرور) في ملف `.env` منفصل لزيادة الأمان.
- **الاختبارات المتغيرة (Parameterized Tests):** استخدام المصفوفات لاختبار أكثر من منتج بنفس الكود دون تكراره.
- **التجميع والخطافات (Grouping & Hooks):** استخدام `test.describe` لتجميع الاختبارات، و `test.beforeEach` لتجهيز الحالة قبل كل اختبار.
- **اختبار متصفحات متعددة (Cross-Browser):** الكود معد للعمل على (Chromium, Firefox, WebKit).

## 🛠️ هيكلية المشروع (Project Structure)

```text
PWAssignment/
├── .auth/                  # يحتوي على ملف الجلسة المحفوظة (Session) لتخطي تسجيل الدخول
├── pages/                  # يحتوي على كلاسات POM (LoginPage, CartPage, إلخ)
├── tests/                  # يحتوي على ملفات الاختبار لكل ميزة
│   ├── auth.setup.ts       # ملف تسجيل الدخول وحفظ الجلسة
│   ├── addtocart.spec.ts   # اختبارات الإضافة للسلة
│   ├── checkout.spec.ts    # اختبارات الدفع
│   ├── login.spec.ts       # اختبارات صفحة الدخول (تتجاهل الجلسة المحفوظة)
│   ├── remove.spec.ts      # اختبارات الحذف
│   └── sort.spec.ts        # اختبارات الترتيب
├── .env                    # ملف المتغيرات (يجب إنشاؤه محلياً)
├── data.ts                 # ملف استدعاء المتغيرات من .env
└── playwright.config.ts    # إعدادات Playwright الأساسية
```

## 🚀 كيفية التشغيل (How to Run)

1. قم بتثبيت الاعتماديات (Dependencies):
   ```bash
   npm install
   ```

2. قم بإنشاء ملف `.env` في المجلد الرئيسي وضع فيه التالي:
   ```env
   URL=https://www.saucedemo.com/
   USER_NAME=standard_user
   PASSWORD=secret_sauce
   ```

3. لتشغيل جميع الاختبارات وعرض التقرير (HTML Report):
   ```bash
   npx playwright test
   npx playwright show-report
   ```

4. لتشغيل الاختبارات في وضع الرؤية (Headed Mode) لرؤية المتصفح:
   ```bash
   npx playwright test --headed
   ```
